クイックスタート
==================================================

■ STEP 1: セットアップを実行

  1. setup.bat をダブルクリック
  2. Pythonのインストール確認
  3. 仮想環境の作成
  4. 必要なパッケージのインストール

  ※所要時間: 3〜5分

■ STEP 2: APIキーを取得

  【Gemini API キー】
  https://makersuite.google.com/app/apikey

  【Google Cloud 認証情報】
  https://console.cloud.google.com/

  必要なAPI:
  ✓ Cloud Vision API
  ✓ Google Sheets API
  ✓ Google Drive API

■ STEP 3: アプリを起動

  run.bat をダブルクリック

  → ブラウザが自動で開きます
  → http://localhost:8501 にアクセス

==================================================
トラブルシューティング
==================================================

Q1: setup.bat を実行してもエラーが出る
→ Pythonがインストールされているか確認してください
   https://www.python.org/downloads/

Q2: "python は認識されていません" と表示される
→ Pythonのインストール時に "Add Python to PATH" に
   チェックを入れ忘れた可能性があります。
   Pythonを再インストールしてください。

Q3: streamlit が見つからない
→ setup.bat を正しく実行できていない可能性があります。
   コマンドプロンプトを開いて以下を実行:

   cd (プロジェクトフォルダのパス)
   venv\Scripts\activate
   pip install -r requirements.txt

Q4: APIキーの設定方法が分からない
→ アプリを起動後、左側のサイドバーに入力欄があります。
   詳しくは SETUP_GUIDE.md の「STEP 5」を参照。
